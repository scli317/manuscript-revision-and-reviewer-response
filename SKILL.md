# Reviewer response and marked manuscript

Prepare a traceable journal revision: preserve each reviewer comment, make a specific and evidence-based response, and connect every claimed manuscript change to the actual final marked manuscript. Apply only the requested deliverables; a paragraph-polishing request does not automatically authorize changes to files.

## Start with the evidence

1. Identify the journal, manuscript ID, decision letter and deadline, editor/reviewer comments, annotated PDF, original manuscript, latest marked and clean drafts, author-provided data, and any formatting reference. Inspect the actual files and modification times; do not assume a familiar filename is current. Preserve originals and the user's subsequent edits; deliver a clearly named copy unless replacement is explicitly requested and safe.
2. Follow the decision letter and user instructions over examples in this skill. Separate requirements from recommendations and format examples. If the letter is provided, verify the editor's actual name and title and the specific submission-file and response-location instructions before drafting.
3. Extract reviewer comments completely and verbatim, preserving numbering, order, symbols, line breaks and reviewer identities. PDF page index, printed manuscript page and revised manuscript page may differ: verify each against the document; never infer a constant offset without checking. For PDF annotations, inspect the annotation text and its actual highlighted anchor; keep the original wording, even where a comment contains an error.
4. Build an internal map for every editor request, formal reviewer comment and in-document annotation: concern; response; evidence or source; actual change; marked-document location; and any open issue. Distinguish analysis, measurements, assumptions, edits and future plans.

## Response and manuscript

- Follow the user's reference document when provided. Default to a short formal editor cover letter and point-by-point reviewer sections: reviewer heading → numbered comment → reviewer comment → response → manuscript changes and location. Use real Word heading styles if a hierarchy is requested; reviewer-comment body text should not be bold unless the user asks for it. Maintain the source document's formatting and preserve unselected content.
- Read [response-templates.md](references/response-templates.md) when composing an editor letter or point-by-point replies. Write comments accurately; thank the reviewer briefly, answer the actual issue, state what was done and why, and cite the evidence and manuscript location. Keep a respectful, concise voice. Distinguish no change plus a reason from an actual revision.
- Do not state that figures, files, analyses or changes were submitted or completed until evidence confirms them. Never invent measurements, CFD settings, numerical results, locations, citations, figures, tests or agreement. Do not present a hypothetical example as measured or simulated data. Clearly label missing inputs and preliminary interpretations; when requested, use red text for unresolved response content. Never present synthetic, cleaned, interpolated or demonstration data as original CFD output; describe their provenance and processing accurately.
- If comments request evidence that is unavailable, do the feasible analysis, state the limitation plainly, narrow interpretations and engineering guidance, and explain what additional comparison would test the claim. Do not imply that a rheology fit, grid comparison, similarity to another simulation, curve smoothness, higher mesh density, or plausible mechanism constitutes independent validation or proves accuracy. Comparable relative trends also remain conditional on model and sampling limitations.
- For scientific specifics, distinguish mass concentration, density, specific weight, volumetric flow and mass flow; verify units, reference frames, directions, geometry, operating conditions and per-case settings before asserting equivalence. For rotating-flow statistics, equal angle windows at different speeds have different physical durations; check startup exclusion, sampling windows and cycle-to-cycle evidence. Do not overstate local effects or extrapolate beyond the available simulation cases.
- When editing a marked manuscript, make real Word tracked changes if requested; colored text, highlighting or a filename alone does not establish track changes. When a prior marked draft has untracked changes, compare the original against a temporary accepted copy of the current final manuscript with Word's compare feature, if available. Save a new marked document and check both the final visible text and original view, formulas, figure references, images, tables, and tracked-change counts. A reconstructed comparison records differences; it does not reconstruct historical authors or edit history. Change revision authors only when expressly requested. Inspect unmarked changes and report unresolved structural differences, including equation objects.

## Page and line references

Read [marked-line-numbering.md](references/marked-line-numbering.md) whenever response locations are requested. The user prefers page and line references that match the marked document **with all revisions displayed**, unless the journal or user specifies another view. In Word, generating the final-content-only PDF can yield plausible but incorrect line numbers. Render or inspect the chosen view, identify the exact changed sentence, equation, figure caption or table, and transcribe its actual page and printed line numbers. Verify sample references against the user's screenshots if provided. If view, pagination or the actual location is uncertain, do not invent a reference: keep a visible pending placeholder or explain the blocker.

Update only locations when asked to change only page/line references; preserve comment wording, response prose and styles, including existing user edits. When a reply claims an amendment that does not exist, identify the discrepancy to the user instead of falsely mapping an unrelated line. After manuscript edits, re-render and recheck all affected references.

## Deliver and verify

Use appropriate document/PDF tools and visually review output. Check that every reviewer comment is accounted for, every line reference resolves in the intended marked view, marked and clean versions show the same final content where requested, all figure/table references and equations are intact, and unsupported claims and placeholders are conspicuous. Explain any material limitation and do not call an incomplete package ready for submission.

For journal figure packages, follow the current editor's actual instructions and example rather than assuming that every journal requests the same layout or upload categories. Preserve scientific image geometry and data; do not regenerate scientific images or fabricate or smooth data merely to improve appearance. If assembling multi-panel figures, compare every panel against the manuscript and retain readable captions and original high-resolution/vector sources.

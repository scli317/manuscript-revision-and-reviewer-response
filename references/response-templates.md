# Reusable revision correspondence templates

Use only verified names, dates, manuscript metadata, completed changes, and files actually accompanying the revision. The editor's decision letter controls requirements. Adapt structure to the user's source template and journal; do not include an invented checklist or a submission claim in a draft still under preparation.

## Editor cover letter

```text
Date: [date]
To: [editor name and verified title]
[Journal]
Re: Manuscript [ID]
Title: [title]
Authors: [authors as submitted]

Dear [editor] and [handling editor if applicable],

Thank you for the opportunity to revise our manuscript and for the reviewers' comments. We appreciate the time and care devoted to evaluating our work.

We have considered each comment. The principal revisions address [specific verified changes and remaining limitations].

[If this is the actual submission package: list the files that actually accompany the revision, as required by the journal.]

Our point-by-point responses follow, with references to the corresponding changes in the marked manuscript.

Sincerely,
[verified corresponding author, on behalf of the authors]
[verified affiliation and contact, if appropriate]
```

## Point-by-point response

```text
Response to Reviewer [number]

Comment [number]
[Reviewer comment reproduced faithfully and in full.]

Response
Thank you for this comment. [Answer the specific concern, distinguish what the evidence shows from limitations, and identify the action actually completed.]

Manuscript changes and location
Please see the marked revised manuscript, page [x], lines [y–z].
```

- For an annotation, identify both the printed original-manuscript page and annotated PDF page, when verified. Keep separate from revised-marked page/line citations.
- For an explanation with no manuscript edit, say so accurately; do not present an unrelated passage as the new change. If relevant, cite an existing passage as background and distinguish it from a revision.
- For multiple changes, list each relevant page/line span. Figure captions and equations should be cited by the actual line or immediately preceding numbered line, in addition to figure/equation number.
- If evidence is missing, use an explicit placeholder such as `[AUTHOR INPUT NEEDED: actual model density and source]` and propose a cautious preliminary interpretation when useful. Do not declare an analysis complete.
- For absent independent validation, explain what data are available, what those data support, what is missing, and what conclusions remain provisional. A plausible explanation does not establish causality.
